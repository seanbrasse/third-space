# Third Space

Private multiplayer pixel-world prototype for eight friends. This baseline imports the existing local lounge, avatar customization, movement/navigation, local SQLite access, chat, board, soundboard and Garden Dash code.

Use Node 24 and pnpm 11. Run `pnpm install`, then `pnpm dev`. Tests: `pnpm test`; types: `pnpm typecheck`; production: `pnpm build`.

The game/API default to localhost:2567 and the web app to localhost:3000. Native voice and public hosting are not configured. Local credentials, SQLite/user data, PRD source documents, generated archives/build files and screenshot artifacts are excluded from this repository import. Existing originals remain on Sean’s Mac.
